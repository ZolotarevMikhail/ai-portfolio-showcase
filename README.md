# Витрина: изображения и видео (нейромедиа)

Одностраничная витрина из трёх проектов-работ: изображения (мини-человечки),
короткие ИИ-ролики и полный процесс «сценарий → готовый ролик с титрами».
Видео проигрываются прямо на странице — удобно давать одну ссылку заказчикам
(например, на бирже, где встроить ролик нельзя).

## Страница

`https://zolotarevmikhail.github.io/ai-portfolio-showcase/`

## Что под плашкой «Изображение / видео»

- **Проект 1 — изображения:** серия «мини-человечки» (2 работы с промптами).
- **Проект 2 — короткое видео:** мотоциклист в закате (5 сек) — плейер на странице.
- **Проект 3 — сценарий → ролик:** ролик про мини-человечков «Море зовёт!»
  (20 сек, музыка и титры) + ссылка на репозиторий с сценариями, промптами
  и скриптами.

## Особенности

- один файл `index.html`, без внешних библиотек и CDN;
- светлая и тёмная темы (авто по системе + кнопка-переключатель);
- адаптив: телефон — компьютер (от 400 px);
- медиа (картинки и mp4) лежат в репозитории — страница автономна.

## Состав репозитория

```
index.html            сама витрина
images/               картинки проекта 1
videos/               ролики проектов 2 и 3
```

## Запуск

Витрина — статичный файл: открылась по ссылке — работает. Локально:
двойной клик по `index.html`.
